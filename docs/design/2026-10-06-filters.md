# DeepLabeling — slice 3: filters

**Status:** approved 2026-10-06 · plan 3a (the core) implemented; 3b (the UI) next
**Scope:** slice 3 of [the app foundation](2026-10-04-app-foundation.md#slices): box size,
overlap between labels and Label/Prediction IoU become conditions of the one queue source,
`ImageFilter`, each highlighting what made it hold. It replaces the legacy app for hunting
with filters. Everything slices 1 and 2 built stays as it is, except where this spec says so.

## Why

Hunting is the third of the [daily workflows](2026-10-04-app-foundation.md#why): find the
boxes that are wrong in a 45k-image dataset by what they look like, then page through only
those. The questions it answers:

- **which boxes are tiny, or span the frame**, of a class or of any class;
- **which labels are stacked** on each other: one object labelled twice, or as two things;
- **which labels the model does not see**, and **which objects nobody labelled**.

The legacy app answered them with a second filter system beside its navigation, whose
settings drifted from what its widgets showed, whose IoU filter went blind after a restart,
and whose overlap filter selected images its highlighter drew nothing on
([legacy-defects.md](../knowledge/legacy-defects.md)). Each of those is a rule below.

## Decisions

| Question | Decision |
|---|---|
| How filters are built | **Conditions of `ImageFilter`**, in the existing streaming build. A precomputed index was the alternative: a third cache to keep fresh, and the legacy app's main source of stale results |
| Size and class | **On the same box**: "has a car 10–30 px wide" is one box that is a car and is that wide, never a car beside some other small box |
| Size units | **Width and height ranges, in px or in % of the frame** (one switch). The legacy pixel area (px²) is not kept: it is hard to reason about |
| Stacked boxes | **Always visible**: a box that another box overlaps at IoU ≥ 0.9, of any class, shows how many are stacked on it (`car ×2`), whatever the queue |
| Name | **As slice 1 built it**: case-insensitive, on the dataset-relative path. The legacy match-case option is not kept |
| A model condition with no model ready | **The queue waits**, and builds once the model is ready. With no model at all it stays empty and says why; the condition is never dropped silently |

## Conditions

Each condition is a frozen dataclass of `core/queue.py` with `test`, `describe`, `highlight`
and its JSON form ([the queue](2026-10-04-app-foundation.md#queue)). Ranges are inclusive
at both ends, either end may be left open, and a typed value is never clamped
([matching.md](../knowledge/matching.md#overlap-between-labels)).

### Boxes: size, on the same box as the class

- **Holds when one box** of the chosen classes (any class when none is chosen) has a width
  and a height inside their ranges.
- **In %**, the width and height are the box's share of the frame's, read from the label's
  normalised coordinates: no image is opened.
- **In px**, they are scaled by the frame's size, read from the file header with EXIF
  orientation honoured, never by decoding
  ([caches.md](../knowledge/caches.md#image-sizes)). An image whose header cannot be read
  does not match, and is counted.
- **Highlights** the boxes that matched.
- In the queue editor, "has" with a size is this condition; "has" without one stays slice
  1's class condition. "Lacks" takes no size.

### Overlap between labels

- **Holds when some pair of labels** in scope overlaps at an IoU inside the range. Scope is
  *different classes*, *same class* or *any*; the range defaults to 0.5–1.0, and 0.99–1.00
  isolates exact duplicates ([matching.md](../knowledge/matching.md#overlap-between-labels)).
- **Highlights** every box of every such pair. The condition and its highlight are one
  predicate, so what the filter selects is what the canvas shows.
- Pairs are counted in O(b²) per image, never worse
  ([legacy-defects.md](../knowledge/legacy-defects.md)).

### Stack counts

Separate from any condition, and always on: a box that others overlap at IoU ≥ 0.9, of any
class, shows how many boxes are stacked on it, itself included (`car ×2`). The count is per
box, as [matching.md](../knowledge/matching.md#overlap-between-labels) defines it. The
canvas caption and the inspector's box list show the same text.

### Label/Prediction IoU

From the loaded model's rows in the [prediction store](2026-10-05-model-assist.md#the-prediction-store),
translated through its [class map](2026-10-05-model-assist.md#the-class-map), in one of three
directions ([matching.md](../knowledge/matching.md#the-iou-filter)):

- **Labels the model does not see:** no prediction at or above the lower confidence bound,
  of **any** class, mapped or not, overlaps the label at IoU ≥ the matching IoU. Only labels the
  model could have seen count ([the checkable-class guard](../knowledge/matching.md#the-checkable-class-guard)):
  a class some model class maps to. The upper bound plays no part
  ([one floor and per-kind ceilings](../knowledge/matching.md#one-floor-and-per-kind-ceilings)).
- **Predictions nobody labelled:** a **mapped** prediction inside the confidence range
  overlaps no label at IoU ≥ the matching IoU — including on an image with no label file.
- **Either.**
- **Settings:** matching IoU (default 0.5) and a confidence range (default the root's
  threshold to 1.0), never below the store's floor.
- **Images never inferred** are left out and counted, never passed as clean
  ([caches.md](../knowledge/caches.md#reading-during-a-dataset-pass)).
- **Highlights** the unseen labels. The unlabelled predictions are emphasised in the
  predictions layer, and drawn even when below the display threshold: they are what the
  queue was asked for.

## Building and keeping current

- **The build** is slice 1's streaming job. Conditions run cheapest first: name and review,
  then what the label file alone answers (class, size in %, overlap), then size in px (a
  header read), then the model condition (a store read).
- **One size function**, `image_size(path)` in the core, is header-only and EXIF-aware. Its
  answers are cached in memory for the open dataset, stamped with the file's size and
  mtime ([caches.md](../knowledge/caches.md#label-cache-freshness)), and safe across threads.
- **The model condition reads the store on the build's thread**, through that thread's own
  connection. The model's key, its class map and the dataset are snapshotted when the
  build starts.
- **What a build could not settle is counted** — images never inferred, images of unknown
  size — and shown with the queue.
- **Kept current:** an edit re-tests the edited image, as in slice 1. Predictions arriving
  for an image re-test it, when the queue has a model condition. A model switch or a
  class-map change rebuilds such a queue.
- **Waiting for the model:** while a model is loading, a queue with a model condition waits
  and says so; it builds when the model is ready. With no model loaded, the queue is empty
  and a notice says the queue needs a model.
- **Saved** with the queue for each opening, as every condition is, and restored on every
  launch path ([landmine 7](../../CLAUDE.md#landmines)).

## Window

### The queue editor

Three rows join the editor, seeded from the queue in force, as every row is:

- **Box size**, under the class list: width `[min]–[max]`, height `[min]–[max]`, and px or %.
- **Overlapping labels:** off, or a scope with an IoU range.
- **Model:** off, labels the model does not see, predictions nobody labelled, or either;
  with the matching IoU and a confidence range. It is offered with no model loaded: the
  queue then waits for one.

OK refuses, naming the field, a reversed range, an IoU or confidence outside 0–1, and a size
with "lacks" (`legacy/yolo_labeling/core/ranges.py::range_error`). The dialog stays open
with what was typed. No row is disabled at setup on a condition that can change later
([legacy-defects.md](../knowledge/legacy-defects.md)).

### The queue chip

It describes every condition in words, then what the build could not settle:
`has car 10–30 px wide · labels overlapping, same class, IoU 0.99–1.00`,
`labels the model does not see (IoU 0.50, conf ≥ 0.25) · 1,204 not inferred`,
`· waiting for the model`, `· 3 images could not be sized`.

### The canvas

- Matched boxes use the existing highlight; unlabelled predictions are drawn solid and
  emphasised in the predictions layer.
- Stack counts are part of the caption: `car ×2`.

## Errors

| Situation | What happens | Where it shows |
|---|---|---|
| A range typed reversed, or an IoU or confidence outside 0–1 | refused, naming the field | the editor stays open |
| A size given with "lacks" | refused | the editor stays open |
| A header cannot be read, under a px size | that image does not match; it is counted | queue chip |
| A model condition with no model loaded | the queue is empty | notice, queue chip |
| An image never inferred, under a model condition | left out; counted | queue chip |
| The prediction store cannot be read during a build | the build fails, as any build does | notice |

## Testing

- **Core, on the generated edge-case dataset:** each condition's `test`, `highlight`,
  `describe` and JSON round trip.
  - Size: both ends of every range inclusive; px against % on the same box; an
    EXIF-rotated frame, whose px size must not be transposed; an unreadable header counted.
  - Overlap: each scope; 0.99–1.00 finding byte-identical duplicates; the highlight equal to
    the boxes the test counted.
  - Model: all three directions; an unmapped prediction that sees a label but is never
    "nobody labelled"; the checkable guard; an image never inferred counted, an image
    inferred with nothing found evaluated; an upper bound that never removes a prediction
    from matching.
  - Stack counts: a chain A–B–C where A and C do not touch reads ×2, ×3, ×2.
- **UI:** the editor seeded from the queue in force and its refusals, with its rows'
  geometry asserted; highlights and stack counts read back from the canvas's pixels and
  captions; a queue waiting for the model, rebuilding on a model switch, and re-testing an
  image when its predictions arrive; every new setting across a relaunch.
- **One measurement script**, read-only, for the [targets](#performance-targets).

## Out of scope

- Class groups in the model condition: slice 4's, with Find Bad.
- A precomputed per-image index.
- Matching case in the name condition.
